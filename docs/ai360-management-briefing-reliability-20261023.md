# РЕСАНТА AI 360° — управленческий разговор и голосовое резюме
Дата: 23 октября 2026. Пилот только директор филиальной сети.

## Исправленный сценарий из видеозаписи
Фраза «Там порекомендую, чтобы она продала и закрыла свой план» после обсуждения Шкуран прежде могла определяться как обычные продажи (выдавая снова план/факт), а не как запрос рекомендаций.

Теперь:
- серверный intent-router распознаёт «порекомендую/порекомендуй», «что ей сделать», «как закрыть план», «подскажи действия» и сходные разговорные формулировки как recommendations;
- браузер передаёт их на сервер без перехода на старые правила голосового пилота;
- сохраняется подтверждённый в диалоге менеджер; сервер отдельно проверяет совпадение закрепления, не передаёт чужих клиентов;
- менеджерский план содержит факт/недобор по KPI, сравнение двух завершённых месяцев для клиентов, клиент/действие/ответственный/контроль/критерий результата;
- уже назначенные визиты не дублируются; открытые и просроченные задачи сначала проверяются;
- совпадение ПДЗ по точному юридическому наименованию помечается с требованием сверить контрагента по реквизитам, НЕ выдаётся за точную client_id-связь;
- никакие непроверенные заказы/объёмы не обещаются; снижение закупок в прошлом месяце не является прогнозом закрытия плана;
- нет записей в CRM: никаких INSERT/UPDATE/DELETE задач, клиентов, маршрутов, GPS, продаж.

## Разговорный интерфейс
- От сервера дополнительно приходит короткий проверенный `speech_summary`. Это отдельное поле для озвучки; на экране остаётся полный подробный ответ.
- Для длинных ответов без отдельного резюме применяется ограничение приблизительно 190 символов с окончанием на слове/фразе. Уместно сказать «Расскажи подробнее» для полного прослушивания.
- Кнопка «■ Остановить речь» доступна на экране и прерывает очереди SpeechKit без отключения микрофона. Голосовая команда «Лера, остановись» обрабатывается только после завершения или прерывания текущего воспроизведения (одновременное слушание при речи Леры выключено для предотвращения эха).
- При озвучке не показывается ложный статус прослушивания; таймаут ожидания подробного ответа расширен до 120 секунд.
- Месяцы и даты в серверных текстах выводятся по-русски: «за октябрь 2026 года», «27 октября 2026 года».
- Не менять monthly SpeechKit бюджет, лимиты распознавания и LLM, директорский lazy-load, ограничения Android и авторизацию.

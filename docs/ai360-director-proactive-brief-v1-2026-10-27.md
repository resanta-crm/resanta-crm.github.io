# РЕСАНТА AI360 · Директорский проактивный брифинг V1 (27.10.2026)

## Контракт

Первая версия — **по запросу директора**, без таймера и рассылок. Кнопка в панели Леры «🧠 Брифинг директора · 5 приоритетов» или голосовая команда «Лера, брифинг директора», «Приоритеты дня», «Что сегодня важного?».

- Пять аналитических направлений: **KPI/продажи**, **ПДЗ**, **задачи**, **маршруты/падающие клиенты**, **Триовист/21vek**.
- Для каждого: факт с числом, предложение руководителю, источник данных, дата среза, уровень риска.
- Только проверяемые правила по CRM snapshots; никаких LLM-генераций, галлюцинаций и платных новых запросов. При недоступности Triovist показывается «данных недостаточно», не придумываются цифры.
- Данные по продажам за октябрь — предварительные, отчётная дата импорта может быть 31 октября при текущем 27 октября; если дата будущая, явное предупреждение.
- Просроченные задачи разделены по статусам `approved` и `stale_review` с независимыми `count=exact`; последние **не считаются доказанным неисполнением**.
- Триовист: факт из `triovist_sales_resolved_cache` (исключены дубли импортов), план из `triovist_plans`, давность `triovist_stock_import_log`, отдельная сервисная RPC. Остатки от 13 октября считать устаревшими.
- Менеджеры/Android не имеют доступа: Edge `verify_jwt=true`, проверка конкретного директора user.id + профиля boss, проверка origin; frontend тоже director-only, Android-guard.
- Никаких `insert/update/delete/upsert`, изменения ролей, GPS, импорта, уведомлений, реальных задач или закрытых тестовых поручений. Endpoint не связан с `crm-ai360-task-approval-v1`. Никаких фоновых запросов на логине CRM.
- Пользователь сам открывает окно Леры; кнопка отправляет команду через существующий input, чтобы не ломать озвучку и историю.

## Состав

- `supabase/migrations/20261027093000_ai360_triovist_brief_v1.sql`: единственная агрегирующая read-only RPC `crm_ai360_triovist_brief_v1(date)`, SECURITY INVOKER, EXECUTE только service_role.
- `supabase/functions/crm-ai360-director-briefing-v1/index.ts`: read-only Edge на 5 доменов, отдельная авторизация, обработка устаревших данных.
- `assets/142-resanta-ai360-director-proactive-brief-v1.js`: кнопка + голосовой handle + текст ответа с фактами/действиями/датами.
- `assets/134`: обработка брифинга до общего диалога продаж; `assets/137`: on-demand sidecar; `index.html`: кэш-bust v22.
- `tests/ai360-director-proactive-brief-v1.test.cjs`: права директора, 5 карточек, источники, старый stock, fallback, запрет записи.

## Проверка на Mac

1. Обновить CRM Cmd+Shift+R, открыть Леру.
2. Нажать «🧠 Брифинг директора · 5 приоритетов» — дождаться 5 разделов.
3. Произнести «Лера, брифинг директора» — тот же аналитический маршрут; Лера может озвучить краткое вступление, полный текст остаётся на экране.
4. Проверить на панели суммы KPI, ПДЗ, задачи с `stale_review`, забытых клиентов, Триовист и предупреждение по остаткам от 13.10.
5. В базе `tasks` и `ai360_voice_test_drafts_v1` изменений от брифинга быть не должно.

## Rollback

Если новинка не понравится, убрать `142` из optional loader и вернуть версии `134`, `137`, `index.html` к состоянию до выпуска, не затрагивая существующую Леру. Edge можно оставить неиспользуемым или снять отдельной операцией. Read-only RPC не влияет на рабочие таблицы; не изменять `crm-ai360-task-approval-v1` и RLS.

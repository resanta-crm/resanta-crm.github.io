# РЕСАНТА AI 360° — маршрутизатор вопросов и проверка ответа
22 октября 2026 года. Директорский пилот. Только чтение CRM.

## Исправленный инцидент
Запрос «какие продажи у Шкуран?» иногда приводил к ответу о задолженности.
Причина: в одном LLM-запросе поступали продажи и полная операционная аналитика;
выбор темы и правильность ответа ничем жёстко не проверялись.

## Реализация
- Введён модуль `supabase/functions/crm-ai360-director-v1/intent-router.mjs`.
- Маршруты: sales, debt, tasks, visits, routes, clients, analysis,
  recommendations, multi. Явный новый вопрос приоритетнее предыдущих реплик.
- Прямой вопрос о продажах получает детерминированный ответ из
  `crm_ai360_sales_kpi_snapshot_v1` без вызова LLM; тем самым не расходует
  20-запросный дневной лимит интеллектуальных объяснений.
- Для прямых продаж не вызывается и не передаётся snapshot ПДЗ, задач, маршрутов.
- Для задолженности/задач/посещений/маршрутов/клиентов запрашиваются только
  релевантные сведения `crm_ai360_operations_snapshot_v1`.
- Для сложного объяснения и рекомендаций модель получает нужные для этого
  проверенные источники, лимит и серверный JWT-контроль сохранены.
- Сгенерированный ответ проверяется на соответствие теме и присутствие
  названных сумм BYN среди чисел выбранного evidence. При нарушении
  выдаётся безопасная сводка, не исходный сомнительный текст.
- Никаких записей в tasks, clients, routes, sales, GPS и ПДЗ.

## Проверка в кабинете директора
1. «Какие продажи у Шкуран?» — ответить только план/факт/выполнение/до плана.
2. «А сколько осталось до плана?» — с учётом контекста; при прямом
   вопросе о плане/факте используются только данные продаж.
3. «А почему она отстаёт?» — перейти к аналитике причин и клиентам,
   различать подтверждённые факты и предположения.
4. «Какая просроченная задолженность у Шкуран?» — ПДЗ, не продажи.
5. «Какие просроченные задачи у Шкуран?» — задачи, не ПДЗ.
6. «Какие клиенты снизили закупки?» — клиентский анализ за закрытые периоды.

## Ограничения
Авторизованный живой диалог пользователя после развёртывания ещё не проверен.
Релевантность ответов модели не гарантируется математически во всех вопросах:
защита проверяет тему и доступные денежные суммы; для глубокой аналитики
по-прежнему требуется контроль руководителя и проверки источников.
Месячный бюджет озвучки и лимит LLM не менялись.

## Откат
Вернуть прежний файл `supabase/functions/crm-ai360-director-v1/index.ts`
из коммита до изменения, убрать импорт `intent-router.mjs`, выполнить
переустановку одной из предыдущих Edge-версий. Никаких миграций и изменений
таблиц не было.

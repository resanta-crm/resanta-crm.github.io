# RESANTA AI 360 — директорский диалог по продажам и KPI · 22.10.2026

**Развёрнуто как ограниченный пилот, требуется проверка реального диалога в браузере пользователя.**

## Статус и безопасность
- Директорский модуль: `crm-ai360-director-v1` в Supabase; обязательный действующий JWT, проверка Auth ID, роли `boss` и точного имени в `public.users`.
- Только сервер читает `purchase_history`, `manager_kpi_plans`, `crm_import_status` через функцию `crm_ai360_sales_kpi_snapshot_v1`.
- `crm_ai360_llm_claim_v1`: максимум 20 оплачиваемых вопросов в сутки по Минску; таблица `crm_ai360_llm_usage_v1` с RLS, без доступа `anon` и `authenticated`. Содержимое диалогов в базе не хранится.
- Нет автоматических действий, создания задач или обновления продаж/GPS. API-ключ OpenAI только в Edge secrets. Запрос к модели — только после явного вопроса.
- Android и Android WebView отключены по профилактике повторения сбоя входа 22.10; существующие 134/135/136 не загружаются при входе. Небольшой скрипт 137 создаёт кнопку после загрузки CRM, а остальные модули загружает **только после клика директора**. Это исключает новую нагрузку на вход сотрудников.

## Источники / границы чисел
- Месячная отгрузка `purchase_history` (BYN), месячные планы `manager_kpi_plans` и дата обновления из `crm_import_status`.
- Группировка по полю `manager_name` импортной продажи; план есть для трёх менеджеров Витебска. **Планы филиальной сети пока отсутствуют в проверенном источнике**; AI не должен утверждать, что рассчитано выполнение каждого филиала.
- История 2025 по менеджерам не имела `manager_name`; baseline строится по текущей привязке `client_id → clients.manager_name` и может быть неполным. Итог сети считается отдельно от планов менеджеров.
- Данные помесячные, точного дневного оборота нет. Октябрь 2026 на 22.10 неполный; сравнение с полным октябрём 2025 требует явной оговорки.
- Текстовые значения из CRM считаются недоверенными, в системном промпте запрещено выполнять их инструкции и придумывать цифры.

## Проверка директором
1. После зелёной сборки Pages открыть `https://resanta-crm.by`, выполнить Ctrl+F5, войти в CRM на ПК.
2. Нажать `🎙 РЕСАНТА AI 360°` в шапке (не Android), затем задать текстом или голосом: **«Кто из менеджеров отстаёт от плана в октябре?»**
3. Спросить: **«А почему?»**, затем **«Что предлагаешь сделать?»**. Помощник должен держать контекст, не объявлять гипотезы фактами и не создавать задачи.
4. Проверить, что есть дата импорта, суммы BYN, а планы менеджеров **не выдаются за планы филиалов**.
5. Проверить сотрудником другой роли: у него нет кнопки; на сервере любой запрос без валидной директорской сессии возвращает отказ.

## Проверено без пользовательской сессии
- Миграции v1/v2 выполнены, SQL snapshot за октябрь возвращает валидные значения и предупреждения.
- RPC и таблица квот закрыты для `anon`/`authenticated`, доступны только `service_role`.
- Edge Function получила статус `ACTIVE`, `verify_jwt=true`.
- Скрипты не инициируют сетевые запросы при входе, а голос не включается без пользовательского действия.

## Пока не подтверждено
- **Фактический ответ модели и синтез Леры после интеграции**: нужен тест в авторизованном браузере директора.
- Отдельный менеджерский и филиальный YOY по полноценным источникам потребует дальнейшей нормализации данных.
- Уязвимости других существующих таблиц без RLS выявлены при аудите, **не исправлялись автоматически**, чтобы не сломать рабочие разделы.

## Откат
Удалить только одну строку с `137-resanta-ai360-lazy-launch-v1.js` из `index.html`. Новый UI и обращения к AI отключатся, существующая CRM и все основные голосовые файлы останутся в прежнем режиме. Edge Function можно оставить без использования либо отключить отдельно.

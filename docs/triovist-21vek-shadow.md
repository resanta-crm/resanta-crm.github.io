# Triovist / 21vek — собственный парсер

С 11.09.2026 shadow-контур используется как безопасный staging перед рабочим Triovist. В production попадает только полностью проверенный снимок.

## Согласованный состав данных

Собираем и используем в рабочем Triovist:
- текущую цену; при отсутствии товара и нулевой цене на странице сохраняется последняя положительная цена, а наличие ставится `нет`;
- наличие;
- наличие описания и актуальный текст описания;
- гарантию;
- количество фото;
- количество видео, уже размещённых на карточке 21vek;
- рейтинг;
- отзывы и их реальное общее количество;
- количество и текст негативных отзывов;
- негативные отзывы без ответа;
- последний отзыв, его оценку, дату и признак наличия ответа;
- поисковый TOP-30/TOP-60 отдельным модулем.

Собираем пока только в staging, но не используем как production-источник:
- `deliveryDays` — до отдельного подтверждения бизнес-смысла поля.

Не собираем и не переносим в новую логику:
- вопросы и ответы;
- Акция / SALE и производные поля;
- самовывоз Минск;
- внешние HD/YouTube «видео доступно / можно загрузить».

## Защита production-cutover

Перед переключением снимка функция `triovist_21vek_promote_shadow_v1` проверяет:
- полный успешный прогон карточек без ошибок;
- количество карточек равно текущему реестру;
- каждая карточка совпала по `manager_email + card_key`;
- URL карточек не изменились;
- все поисковые фразы получили строку в TOP-снимке;
- production RPC доступен только `service_role`.

Если хотя бы одна проверка не проходит, рабочие `triovist_content_*` не переключаются.

Старые платные импорты не удаляются: они остаются историей и могут использоваться для диагностики/отката. Ежедневный основной запуск выполняется в 06:17 по Минску; резерв карточек — в 08:17 без повторного production-cutover.

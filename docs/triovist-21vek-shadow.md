# Triovist / 21vek shadow parser

Контур намеренно изолирован от рабочей CRM.

## Согласованный состав данных

Собираем:
- текущую цену;
- базовую цену до скидки;
- наличие;
- наличие описания и актуальный текст описания;
- гарантию;
- количество фото;
- количество видео, уже размещённых на карточке 21vek;
- рейтинг;
- отзывы;
- количество и текст негативных отзывов;
- негативные отзывы без ответа;
- последний отзыв, его оценку, дату и признак наличия ответа;
- `deliveryDays` для Минска — пока только shadow, до отдельной проверки смысла поля;
- листинг TOP-30/TOP-60 будет отдельным модулем и пока не собирается этим парсером.

Не собираем и не переносим в новую логику:
- вопросы и ответы;
- Акция / SALE и производные поля скидки;
- самовывоз Минск;
- внешние HD/YouTube «видео доступно / можно загрузить».

## Безопасность

- Парсер читает только канонические публичные товарные страницы 21vek.
- Результат пишется только в `triovist_21vek_shadow_*`.
- Рабочие `triovist_content_*`, задачи ИИ, продажи, остатки и UI не изменяются.
- История хранит компактные показатели.
- Полный полезный payload хранится только как последнее актуальное состояние карточки.
- Ошибка одной карточки не останавливает весь цикл.
- До отдельного решения руководителя shadow-данные не являются источником истины для рабочей CRM.

# Формат письма 1С для раздела «Уценка»

Тема письма: **Уценка для CRM**

Вложение: **XLSX**. Первый лист.

## Рекомендуемые колонки
Обязательные:
- **ID** — уникальный и стабильный идентификатор конкретной возвратной позиции/партии.
- **Артикул**
- **Номенклатура**
- **Количество**
- **Цена** — базовая цена с НДС, BYN.

Желательные:
- **Причина** — возврат клиента / сервис / другое.
- **Документ**
- **Дата**
- **Серийный номер**
- **Комментарий** — что известно о состоянии из 1С/сервиса.
- **Гарантия** — Да/Нет; если пусто, CRM считает, что гарантия сохраняется.
- **Гарантия мес**
- **Условия гарантии**

Импортёр понимает также распространённые варианты заголовков: Код/SKU, Товар/Наименование, Остаток, Цена с НДС, Дефект/Состояние и т.д.

Письмо должно содержать **полный текущий остаток уценки**, потому что успешно импортированный снимок используется как актуальный реестр. Позиции, отсутствующие в новом полном снимке, переводятся в архив, если они ранее не были отмечены как проданные.

# РЕСАНТА AI 360° — исправления по видео 24.10.2026, обзор сделанного и открытый план

## Утверждённые и внедрённые доработки (24 октября)
1. Свободная команда «А расскажи мне весь план», «Прочитай предыдущий ответ», «Расскажи весь план полностью» возвращает **полную озвучку уже полученного ответа**, не делает повторного запроса к OpenAI/CRM и не меняет сохранённый разбор.
2. Для уже активированного диалога с «Привет, Ресанта» после переключения в другую вкладку ввод остаётся выключенным. При возвращении в CRM в течение **3 минут** и сохранённом явном согласии восстанавливается контекст вопроса без повторного приветствия. По истечении 3 минут нужно снова сказать кодовую фразу. При закрытии окна/мини-плеере/выходе из страницы эта кратковременная возможность аннулируется. Содержание диалога для этого не записывается в localStorage.
3. Панель статуса ограничена высотой 38px, длинные сообщения обрезаются многоточием с полной подсказкой при наведении. Индикатор микрофона вынесен на отдельную полосу высотой 5px; в скрытом состоянии не занимает места.
4. Кнопка «Отметить ошибку» открывает модальную форму поверх чата вместо расширения панели ввода. Добавлены aria-modal, фокус на поле выбора и Escape для закрытия. Отчёт только копируется в буфер по явному нажатию: никаких фоновых передач данных или записей в CRM.

## Уже реализованные направления РЕСАНТА CRM
- Клиенты, VIP, менеджеры, планы продаж и KPI, месячные показатели, данные 1С, работа с ПДЗ и задачами.
- Маршруты менеджеров, GPS-контроль посещений, сверка торговых точек, технические остановки, директорский разбор спорных GPS-визитов и анализ забытых/перспективных клиентов.
- Раздел Triovist/21vek: импорт продаж, анализ остатков и заявок, ИИ-задачи по подгруппам, собственный парсер карточек 21vek, сравнение цен с МРЦ и позиции в листинге, парсер конкурентов по характеристикам, менеджерские и директорские разделы.
- Складские операции и ТСД: приёмка, сканирование, инвентаризация, работа с номенклатурой и заказами.
- РЕСАНТА AI 360°: директорский read-only пилот. Русское распознавание речи; Яндекс Лера/Даша; фраза активации; проверенная аналитика менеджеров, клиентов, продаж, маршрутов, задач и ПДЗ; короткие/полные ответы, тексты и кнопки пометки ошибок, фоновое воспроизведение аудио с отключением фонового микрофона.
- Системные предохранители: проверка директорской роли, подтверждение закрепления клиентов за менеджером, недопущение чужих клиентов в персональном анализе, отказ от выдачи падения KPI как доказанного падения общей выручки. Voice UI загружается отдельно и лениво, без риска затронуть Android/login обычной загрузкой.

## Отдельные идеи, пока не внедрённые
1. Голосовое **согласование и создание** поручений — только после повторного подтверждения, проверки роли, дубликатов и аудита.
2. Проактивный ежедневный директорский AI-брифинг с сигналами по продажам, дебиторке, потерянным клиентам и маршрутам.
3. Приватный навык Алисы с безопасной привязкой аккаунта; подписка Плюс сама по себе не даёт API доступа к внутренней CRM.
4. Необязательная кнопка/команда запуска Яндекс Музыки, без обещания API управления воспроизведением.
5. Интеграция AI/AR-очков с дисплеем и SDK для демонстрации аналитики на совещании: оборудование ещё не проверено на месте.

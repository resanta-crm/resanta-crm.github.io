## Реализованные пункты 1 и 2
### 1. Русская озвучка
- Только при передаче в Яндекс SpeechKit преобразуются месяцы `10.2026` / `2026-10` и даты `23.10.2026` / `2026-10-27` в естественную русскую речь (остальные цифры и SKU неизменны).
- Суммы BYN произносятся как «белорусских рублей / белорусских рубля / белорусский рубль», с копейками для ненулевых дробных сумм. Сами данные и экранная запись сумм неизменны.
- Краткое голосовое сообщение теперь маркируется «Озвучен краткий итог», а не «ответ полностью». Команда «Расскажи подробнее» воспроизводит полный текст.
- Изменены исключительно директорские необязательные скрипты `134` и `136`. Они загружаются лениво и не активны при входе в CRM или на Android.

### 2. Рекомендации руководителю
- `crm-ai360-director-v1` генерирует по подтверждённой базе для конкретного менеджера проект действий по трём клиентам с наибольшим снижением связанных закупок за последний закрытый месяц.
- Если у клиента уже назначен визит в `route_plans`, ИИ не предлагает вторую встречу. Вместо этого рекомендует подготовить потребность, незакрытые заявки, наличие товара и условия оплаты к существующему визиту.
- Если у клиента есть открытые/просроченные задачи, система требует сверить их до нового поручения.
- Если в актуальной ПДЗ есть точная текстовая пара по юридическому названию и менеджеру, предупреждает о долге, но НЕ утверждает совпадение по клиентскому ID и предлагает сверить реквизиты.
- ПДЗ упорядочивается по сумме; остатки менее 1 BYN выделены на техническую сверку, а не как первоочередной обзвон. Просрочка и дата отчёта показаны.
- Недовыполнение KPI не трактуется как доказательство снижения общей выручки. Дополнительный серверный фильтр блокирует необоснованное утверждение о падении общей выручки без сопоставимых периодов. Клиентские снижения считаются отдельно по закрытым месяцам.
- Все поручения — проекты рекомендаций. Никакой автоматической записи задач/визитов/счетов/сделок/изменений планов.

## Проверки
- GitHub Actions: `Validate AI360 optional JavaScript` — проверка синтаксиса и регрессий русских дат, грамматики BYN, речи с кратким статусом, маршрутов, открытых поручений, межменеджерской безопасности и сортировки ПДЗ.
- Supabase `crm-ai360-director-v1` версия 12, JWT проверяется, доступ только подтверждённому директору. RPC для аналитики доступны серверной роли, не напрямую браузерным пользователям.
- Не проводился авторизованный реальный голосовой end-to-end тест в компьютере руководителя после текущего релиза: его нужно сделать отдельно.

## Риски/ограничения
- Падение закупок не равняется готовому заказу. Настоящий потенциал требует уточнения заказа, SKU, наличия и дебиторских ограничений; соответствующие данные в эту итерацию не подключались.
- ПДЗ сопоставляется по точному названию, не по `client_id`; совпадение названия не является гарантией совпадения контрагента.
- Прямая голосовая команда «согласовать поручение» пока не создаёт задачи.
- Месячный лимит SpeechKit 5000 RUB и действующий дневной лимит интеллектуальных обращений не изменены.

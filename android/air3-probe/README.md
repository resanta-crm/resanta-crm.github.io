# AIR3 V2 · первый аппаратный тест

Это **только независимая проверочная APK**, а не новая Лера и не боевое приложение CRM.

- Пакет: `by.resanta.air3probe` — не затрагивает существующее APK менеджеров.
- Не запрашивает INTERNET, не подключается к CRM, не получает пароль и не сохраняет данные.
- Проверяет доступность **локального (on-device)** русского распознавания речи, WebView и MediaProjection. Отсутствие локального STT не означает неисправность микрофона.
- Добавлена кнопка №4: **явный четырёхсекундный тест настоящего микрофона** через Android MediaRecorder. Файл создаётся во временном кеше, воспроизводится только на очках, удаляется после завершения и при сворачивании приложения. INTERNET по-прежнему запрещён в манифесте. Нет фоновой записи.
- Тест фраз «Открой продажи», «Перейди в ПДЗ», «Покажи Триовист», «Включи трансляцию» выводит только распознанное намерение.
- Никакие действия в CRM и трансляции этой APK пока **не выполняются**.

## Сборка
GitHub Actions: `AIR3 v2 native compatibility APK (isolated)` -> артефакт `resanta-air3-compatibility-debug`.
Локально (JDK 17, Android SDK 35, Gradle 8.11.1):
```bash
cd android/air3-probe
gradle :app:assembleDebug
```
Выход: `app/build/outputs/apk/debug/app-debug.apk`.

## Испытание на настоящих очках (после предварительной проверки APK)
1. Установить тестовую APK разрешённым способом без перепрошивки.
2. Открыть приложение, выбрать «Проверить устройство».
3. Нажать «Проверить микрофон», при запросе разрешить микрофон, произнести две русские команды.
4. Нажать «Проверить возможность трансляции».
5. В новой версии нажать «4. Проверить настоящий микрофон», один раз разрешить запись и произнести короткую фразу. Через четыре секунды запись должна локально воспроизвестись и удалиться.
6. Зафиксировать: версии Android/WebView, наличие SpeechRecognizer, слышна ли локальная пробная запись, удобство кнопок, результат проверки MediaProjection.
7. Закрыть приложение. Оно не хранит никаких CRM-сеансов.

Если локальное распознавание недоступно — это не стоп-фактор для проекта: в следующем этапе подключается существующее OpenAI STT через защищённый API с согласия владельца. Никакой автоматической передачи CRM-данных на сторонний SDK в первом тесте нет.

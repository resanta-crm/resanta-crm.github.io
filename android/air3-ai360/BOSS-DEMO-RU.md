# INMO AIR3 · показ руководителю без нажатий во время разговора

**Цель показа:** руководитель надевает подготовленные очки, говорит
«Привет, Лера, какие продажи сегодня по Витебскому филиалу?», затем
«Привет, Лера, какая просроченная задолженность?» и слышит ответы
**из настоящей CRM** голосом Яндекс Лера в динамиках AIR3.

## Подготовка владельца ПЕРЕД передачей очков

1. Очки INMO AIR3 с Wi-Fi и зарядом; установить тестовый APK
   из GitHub Actions этого PR, артефакт resanta-ai360-air3-native-debug.
   Приложение «РЕСАНТА AI 360 · INMO AIR3» не меняет APK менеджеров.
2. На MacBook с директорской CRM открыть https://resanta-crm.by/air3-control.html .
3. Первое подключение: создать шестизначный код на MacBook (действует 2 минуты),
   ввести код в очках, «Подключить очки по коду»; на MacBook «Разрешить вход»,
   на очках «Проверить подтверждение владельца». Повторный вход через аппаратный
   ключ может требовать только разрешения на MacBook, если привязка прошла.
4. На очках нажать «🎙 Демонстрация: Привет, Лера», ознакомиться с условиями
   отправки речи в OpenAI STT и нажать «Включить». Проверить статус показа.
5. Если смотреть на экран через scrcpy, запускать с --no-audio. Убедиться,
   что звук ответа слышен именно из динамиков очков, не из MacBook.
6. Дать очки руководителю; в течение активного окна демонстрации ему не нужно
   касаться кнопок или входить в CRM.

## Четыре живых вопроса для показа

- «Привет, Лера, какие продажи сегодня по Витебскому филиалу?»
- «Привет, Лера, сколько просроченной дебиторской задолженности?»
- «Привет, Лера, как выполняется план продаж?»
- «Привет, Лера» → Лера говорит «Слушаю вас» → «Какие клиенты падают?»

Если доступный отчёт старше сегодняшнего, Лера обязана назвать дату данных.
Ответы берутся из CRM, а не из заранее записанного сценария.

## Защита, время работы и аппаратная проверка

- Показ только при открытом приложении и явном согласии владельца.
  Фрагменты речи отправляются в существующий защищённый OpenAI STT;
  тишина не загружается. Без сервисных ключей, JWT и пароля CRM в очках.
- Не более 15 минут, не более 20 речевых фрагментов, при сворачивании
  приложение прекращает демонстрацию. Токен в RAM, серверная сессия
  максимум 60 минут и idle максимум 10 минут с возможностью отзыва.
- Физический тест обязателен: микрофон → текст → продажи → долг →
  голос Yandex Lera в динамиках очков → следующий вопрос → отзыв доступа.
- После показа закрыть сеанс в приложении и отозвать на MacBook.
- Это не системная Siri на выключенном экране. Без аппаратного теста
  не утверждать, что фоновые и заблокированные режимы работают.

Этот PR не изменяет production CRM, CONNECT, APK менеджеров и Edge server.

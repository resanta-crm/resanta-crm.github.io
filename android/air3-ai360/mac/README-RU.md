# РЕСАНТА AI360 · INMO AIR3 · USB без ручного ввода кода

Это тестовый комплект для MacBook Neo и **оригинальной CRM** на экране очков.
На стороне сайта никаких новых политик доступа не устанавливается.

## Подключение (кабель нужен только для подготовки)

1. Распакуй комплект в одну папку на MacBook. Не вынимай APK из этой папки.
2. Подключи AIR3 по USB-C и разреши USB-отладку на очках.
3. Двойной клик по `AIR3-USB-Connect.command` (если macOS спросит —
   разреши запуск через контекстное меню Finder «Открыть»).
4. Помощник проверит / установит отдельное приложение AIR3 и откроет
   `https://resanta-crm.by/air3-control.html` в браузере MacBook.
   Важно: там должен быть активен **твой директорский вход в CRM**.
5. На MacBook нажми **«🔌 Подключить очки по USB · без ввода кода»**.
   Временный пароль привязки уйдёт только в системный буфер обмена
   MacBook и через ADB в очки. Цифры нигде вводить не нужно.
6. Пульт покажет заявку — нажми **«Разрешить вход»**.
   Очки самостоятельно проверят разрешение и примут временную голосовую
   сессию. Если Mac просит доступ к буферу обмена — разреши в своём браузере.
7. В очках должен отображаться **настоящий сайт**
   `https://resanta-crm.by/index.html`. Войди в него **под своей
   штатной учётной записью CRM**: USB-подтверждение Леры не является
   логином веб-сайта и не передаёт пароль / JWT через USB.
8. Нажми вверху «🎙 Привет, Лера», ознакомься с разрешением
   микрофона и включи показ. Кабель можно отсоединить.

## Сценарий для руководителя

- «Привет, Лера, какие продажи по Витебскому филиалу?»
- «Привет, Лера, какая просроченная задолженность?»
- «Привет, Лера, как выполняется план продаж?»

Интерфейс сайта настоящий, показатели не подменяются подготовленной картинкой.
Голосовое управление разрешено **только при открытой странице** и после
включения демонстрации. Не Siri в выключенном экране.

## Завершение (снова USB)

1. Подключи AIR3 к MacBook.
2. Двойной клик `AIR3-USB-Disconnect.command`.
3. Программа отзывает голосовой токен на сервере и удаляет локальные
   данные приложения и авторизацию сайта на очках. Если отзыв не
   подтвердится, откроется пульт — нажми **«Отключить»**.
4. Независимо от подключения доступ к AI360 истекает не позднее 60 минут,
   при бездействии — 10 минут. Владелец может отозвать его на MacBook
   в любое время, даже без очков.

## Безопасность и честные ограничения

- Временный код **не показывается и не вводится** пользователем, но
  применяется внутри существующего сервера как дополнительная защита.
- Mac clipboard используется один раз; USB-помощник сразу очищает
  значение после отправки. Не запускать на чужом Mac или с чужим кабелем.
- Пароль CRM, JWT и сервисные ключи не вкладываются в комплект.
- Экран и звук именно на **физическом INMO AIR3** должны быть проверены
  до передачи руководителю; успешная CI-сборка не доказывает аппаратную работу.
- Стандартное приложение менеджеров, CONNECT и главная страница CRM
  этим комплектом не изменяются.

Если в браузере нет USB-кнопки, версия пульта ещё не опубликована.
